# 细化每日行程

目标：细化服务端指定的最多两个 Day，补充现有 Stop 的时间、活动说明、核验状态和必要备注，并生成 Proposal 输入。

要求：
- 只能返回服务端指定 Day；不得修改其他 Day。
- 不得新增 Place、Candidate 或 Stop，不得改变 Stop/Anchor identity、地点引用或顺序。
- 可以在确有需要时联网核验动态信息；没有可靠来源时使用 estimated/unverified。
- 不能直接写入 canonical；结果必须经过 Proposal → Apply。
- 如果细化目标必须新增地点，返回 `requiresStage=interests`。
- 只返回 `itinerary.refine.output` 对应 JSON。
