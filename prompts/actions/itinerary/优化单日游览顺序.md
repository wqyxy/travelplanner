# AI 排序：当天

目标：根据用户要求，对服务端提供的 `organizer` JSON 中这一天的地点重新排序。

`organizer.blocks[].places` 中的每一项都只是一个地点。不要区分城市、景点、餐厅或其他类型；进入这里以后全部按同一种 Place 处理。

规则：
- 用户的 `parameters.request` 优先；如果只是要求自动排序，就综合旅行合理性、已有路线事实、少绕路和少往返来排序。
- 只能调整地点顺序，不得新增、删除、替换地点。
- 不得修改地点 ID 或名称。
- 每个输入地点必须且只能出现一次。
- `fixedEndPlaceId` 是这一天的住宿/日终边界，必须保持在本日最后，不参与移动。
- 不得修改 normal / tentative / no_go、endsDay、交通设置、活动、时间或其他字段。
- 未定位地点也必须保留，不能因为缺少路线事实而删除。
- 不得伪造坐标、距离、时长或 geometry。

输出合同仍为 `itinerary.day.optimize.output`：
- `dayId` 必须是当前 Block ID；
- `orderedStopIds` 只返回可移动地点 ID，按新顺序排列，不包含固定的 `fixedEndPlaceId`；
- `title` 和 `explanation` 简短说明排序结果。

只返回指定 JSON Schema。
