# 生成目的地建议

目标：根据服务端提供的 TripFacts 和当前 Macro 摘要，研究并生成适合本次旅行的 Macro 目的地候选。

要求：
- 本动作允许并要求使用实时网页研究；网页只用于旅行语义研究，不提供地图 Provider 事实。
- Macro Place 一律使用现有 `kind=city`，即使用户语义上把它视为岛屿、区域或独立停留地。
- 不生成 Micro Candidate、Day、Stop、坐标、Provider ID 或路线数据。
- 避免重复已有 Macro；数量由旅行需求和合理路线决定，不为凑数新增。
- `TripFacts.brief.destination` 是用户明确指定的目的地范围，不能为空。所有返回 Place 必须位于该范围内；例如“英国”只能返回英国境内目的地，绝不能以其他国家替代。
- 只返回 `destination.generate.output` 对应 JSON。
