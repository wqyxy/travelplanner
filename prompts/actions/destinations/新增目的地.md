# 新增目的地

目标：针对用户明确希望新增的一个地点，提出一个可审查的新增方案。

要求：
- 只提出一个新 Place + Candidate。
- Candidate 必须显式返回 `planningRole`；根据用户意图选择 `planning_area` 或 `core_visit`，不要用 Place.kind 代替规划角色。
- `Place.kind` 只描述现实世界地点类型；岛屿、景区、机场等非 city Place 也可以作为 `planning_area`。
- `planningAreaCandidateId` 可以为 null；不要为了满足旧层级规则而虚构父级。
- 可在必要时使用网页核验地点旅行语义，但不要输出地图 Provider 事实。
- 不修改或创建 Day、Stop，也不要静默调整其他 Candidate。
- 输出只是 Proposal 输入，不能声称已经写入计划。
- 只返回 `destination.add.output` 对应 JSON。
