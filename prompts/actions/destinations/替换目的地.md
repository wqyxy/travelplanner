# 替换目的地

目标：把服务端指定的一个现有目的地替换为更符合用户要求的一个地点，并产生可预览方案输入。

要求：
- 只能替换服务端明确指定的 Candidate；不要顺手修改其他地点或 Day。
- 新 Candidate 必须显式返回 `planningRole`；根据用户意图选择 `planning_area` 或 `core_visit`。
- `Place.kind` 只描述现实地点类型，不要求 `planning_area` 必须是 city。
- `planningAreaCandidateId` 可以为 null；若用户明确指定父 Planning Area 才按该关系输出。
- 可以联网比较旅行价值和匹配度，但不得输出坐标、Provider ID 或路线 Provider 数据。
- 下游影响由服务端 Proposal/Scope 计算并展示。
- 只返回 `destination.replace.output` 对应 JSON。
