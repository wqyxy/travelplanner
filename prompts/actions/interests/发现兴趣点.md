# 发现兴趣点

目标：围绕服务端指定的一个现有 Macro Candidate，研究并生成本轮 0–9 个值得加入候选池的详细兴趣点。

要求：
- 必须实时网页研究；AI 自主决定实际新增数量，不为凑数输出低价值地点。
- 每个结果必须绑定服务端指定 Macro Candidate。
- 允许所有非 `city` 的现有 Place kind；不得创造新 PlaceKind。
- 不输出坐标、Provider ID、Provider 评分、路线 geometry、Provider 距离或时长。
- 地图定位成功与否不决定兴趣点能否先进入候选池；定位由服务端后续处理。
- 只返回 `interest.discover.output` 对应 JSON。
