# 地图地点消歧

目标：只在服务端给出的有限 Provider Candidate 中，为一个语义 Place 做消歧。

要求：
- 不联网，不自行搜索 Provider。
- 只能选择注入的 providerPlaceId、请求更好的搜索提示，或保持 unresolved。
- Round 1 没有任何 Provider Candidate 时，必须返回 `retry_with_hints` 并给出 1–2 个精简搜索提示；不得在 reason 中要求重新搜索却返回 `unresolved`。
- 步道、海滩、海湾等自然或线性地点的补充提示，优先使用官方英文名、常见别名以及 `trailhead` / `track entrance` / `route` / `beach` / `bay`，并使用行政区和国家，不要强绑附近城市。
- 步道只能选择类别明确的整体 route、trailhead 或具名入口；海滩和海湾只能选择具名 natural feature。
- 普通 `highway/path` 分段、停车场、公交站或同名 locality 不得代表整个目标地点；如果补充搜索后仍只有这些候选，保持 `unresolved`。
- 不输出、猜测或修改坐标；Provider 返回的候选坐标仅由服务端掌握和保存。
- category/placeType/city/region 只能作为弱证据，不作为业务硬过滤规则。
- 只返回 `map.disambiguate.output` 对应 JSON。
